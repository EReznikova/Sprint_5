# Sprint 5 — UI-тесты «Доски»

Автоматизированные UI-тесты учебного сервиса «Доска». Тесты написаны на Python с использованием Selenium WebDriver и Pytest.

## Что проверяется

- успешная регистрация пользователя;
- регистрация с некорректным e-mail;
- регистрация уже существующего пользователя;
- вход зарегистрированного пользователя;
- выход из учётной записи.
- попытка размещения объявления неавторизованным пользователем;
- создание объявления авторизованным пользователем.

## Структура проекта

- `tests/` — тестовые сценарии;
- `locators/` — локаторы элементов страниц;
- `conftest.py` — фикстура Chrome WebDriver;
- `.gitignore` — исключения для Git.

## Установка

Нужны Python 3, Google Chrome и ChromeDriver, совместимый с установленным Chrome.

Установите зависимости:

```bash
pip install pytest selenium
```

## Запуск тестов

Из корневой папки проекта выполните:

```bash
pytest -q
```

Каждый тест запускается в отдельном экземпляре Chrome. После выполнения браузер закрывается фикстурой `driver`.
